# Extract Fitted Values from a Compound Poisson-Normal (CPN) Model

This method extracts the fitted values from a model object of class
`"cpn"`.

## Usage

``` r
# S3 method for class 'cpn'
fitted(object, ...)
```

## Arguments

- object:

  An object of class `"cpn"`, typically returned by a model fitting
  function for the Compound Poisson-Normal regression.

- ...:

  Additional arguments (currently unused).

## Value

A numeric vector of fitted values.
